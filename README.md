## Featured research: occupancy forecasts and empty building periods

I developed this first-author study with guidance from Prof. Chong Li. It compares occupancy forecasts and examines how their recommendations agree with recorded camera labels. The public materials include the manuscript, saved outputs, an interactive browser replay, a small offline Python kit, and a notebook.

The fixed hybrid rule found **14 sustained windows across 43 saved test horizons**, with zero camera-label conflicts in 259 recommended fifteen-minute intervals. These are offline observations from one building. They do not establish energy savings or guarantee future performance.

## Try a small reproduction

The occupancy notebook and offline Python kit recompute the fixed policy comparison without training a model. The kit can save a local result receipt that you may review before sharing. If you try it, [report your environment and observed results](https://github.com/stevenchenjy/decision-aware-occupancy-forecasting/issues/new?template=reproduction.yml). A correction or a failed reproduction report is useful too. [Starter tasks](https://github.com/stevenchenjy/decision-aware-occupancy-forecasting/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22) cover Colab, Windows, and accessibility checks.
